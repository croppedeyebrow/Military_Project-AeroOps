# API 문서

이 폴더는 3단계(수집·저장 파이프라인) 이후 생성되는 OpenAPI 문서와 API 참고 자료를 보관한다.

- FastAPI가 자동 생성하는 OpenAPI 스키마는 백엔드 실행 후 `/openapi.json`, `/docs`(Swagger UI)에서 확인할 수 있다.
- 8단계(보안·검증·배포)에서 최종 OpenAPI 문서 스냅샷을 이 폴더에 정리한다.
