# 5단계 — 임무·경보 관리 (Day 11~13)

## 목표

예정 경로·경보와 함께 명령 승인·전달·취소·타임아웃 수명주기를 구현한다.

## 작업

- 임무·경유지·예정 경로 CRUD
- 지오펜스 Polygon 저장·표시
- 배터리 부족, RSSI 저하, 구역 이탈 규칙
- 경보 생성·확인·해제 상태 모델
- 경보 근거값·임계값·rule_version 저장
- 주요 변경 작업 감사 로그 기록
- Command 상태 머신과 전이 검증
- 요청자·승인자 분리와 만료 시각 검사
- dispatch, ACK, 실행 결과 및 단계별 timeout worker
- 취소 요청과 중복 실행 방지
- 명령 상태 타임라인 UI

## 완료 기준

- 예정 경로가 지도에 점선으로 표시된다.
- 세 종류의 경보가 시나리오에 맞게 재현된다.
- 경보마다 판단 근거와 규칙 버전을 조회한다.
- 임무·경보 변경 행위가 감사 로그에 남는다.
- 승인되지 않았거나 만료된 명령은 전달되지 않는다.
- ACK 손실 시 명령을 무조건 재실행하지 않는다.
- 취소 가능·불가능 상태가 정책과 일치한다.

## 산출물

임무 화면, 경보 패널, 규칙 테스트, 감사 로그 예제.

## V03 추가 태스크

- 패킷 손실·지연·배터리 감소 Window Feature 생성
- 규칙·EWMA·Isolation Forest 결과 비교
- AI 추론 오류·지연 시 규칙 기반 Fallback
- Model Version과 Feature Schema Version을 경보 근거에 저장

## V04 운용 문제 반영

- ACK·실행 시작·실행 완료·목표 상태 달성 상태 분리
- 통제권 Lease와 낙관적 잠금으로 상충 Command 경합 시험
- 배터리·잔여 경로·복귀 거리·탑재체 상태 기반 임무 가능성 계산
- 대체 가능 기체와 미수행 임무 구간을 운영자에게 제시
- 반복 경보 억제·상관관계 분석·Incident 생성 구현
