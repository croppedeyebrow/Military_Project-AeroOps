# 5단계 — 임무·경보 관리 (Day 11~13)

## 목표

예정 경로와 운용 구역을 관리하고 설명 가능한 상태 경보를 발생시킨다.

## 작업

- 임무·경유지·예정 경로 CRUD
- 지오펜스 Polygon 저장·표시
- 배터리 부족, RSSI 저하, 구역 이탈 규칙
- 경보 생성·확인·해제 상태 모델
- 경보 근거값·임계값·rule_version 저장
- 주요 변경 작업 감사 로그 기록

## 완료 기준

- 예정 경로가 지도에 점선으로 표시된다.
- 세 종류의 경보가 시나리오에 맞게 재현된다.
- 경보마다 판단 근거와 규칙 버전을 조회한다.
- 임무·경보 변경 행위가 감사 로그에 남는다.

## 산출물

임무 화면, 경보 패널, 규칙 테스트, 감사 로그 예제.
