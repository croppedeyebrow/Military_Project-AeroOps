# 프론트엔드 아키텍처

## 책임과 화면

- 실시간 관제: 지도, 자산 목록, 경보, 선택 기체 상세
- 임무 관리: 임무 지점, 예정 경로, 지오펜스
- 이력 재생: 지도·3D·차트의 동일 시간축 재생
- 관리: 사용자, 자산, 감사 로그
- 명령 콘솔: 요청, 승인, 취소, 타임아웃 및 ACK 상태
- 신뢰성 화면: 패킷 손실률, 지연, sequence gap, 재동기화 상태

## 시각화 규칙

| 대상 | 표현 |
|---|---|
| 전체 드론 | 방향 아이콘, 호출부호, 상태 색상 |
| 실제·예정 경로 | 실선·점선 |
| 선택 기체 | 저폴리곤 GLB와 자세값 |
| 통신 단절 | 회색 마지막 위치와 경과 시간 |
| 구역 | 임무·주의·금지 폴리곤 |
| 명령 상태 | 단계별 배지와 상태 타임라인 |
| 재동기화 | 마지막 sequence와 snapshot 진행률 |

## 상태 관리

- 서버 데이터: TanStack Query
- 실시간 최신 프레임: WebSocket 전용 store
- 화면 선택·레이어: Zustand
- 재생 시각·배속: Replay Controller

장기 이력을 브라우저에 계속 누적하지 않는다. 최신 상태와 짧은 차트 버퍼만 유지하고 기간 이력은 API로 조회한다.

## 컴포넌트 경계

`OperationsMap`, `AssetList`, `AssetDetail`, `Vehicle3DViewer`, `AlertPanel`, `ReplayTimeline`, `TelemetryChart`로 분리한다. 3D 오류가 지도 관제를 중단시키지 않도록 오류 경계를 둔다.

추가 컴포넌트는 `CommandComposer`, `ApprovalQueue`, `CommandTimeline`, `LinkQualityPanel`, `ResyncBanner`, `DeploymentBadge`로 분리한다.

## 안전한 명령 UX

- 명령 생성과 승인을 서로 다른 사용자 행동으로 구분한다.
- 대상 기체, 파라미터, 만료 시각, 요청자를 확인한 뒤 승인한다.
- 취소 버튼은 현재 상태에서 취소 가능한 경우에만 활성화한다.
- timeout과 실패를 같은 상태로 표시하지 않는다.
- 단절·재동기화 중에는 위험 명령을 잠그고 이유를 표시한다.
- UI의 성공 표시는 서버의 최종 상태 이벤트를 받은 뒤에만 확정한다.

## 검증

- 10대 아이콘 갱신 시 프레임 드롭 확인
- 선택 변경 시 GLB 메모리 해제
- WebSocket 재연결과 stale 상태 표시
- 동일 timestamp의 지도·3D·차트 일치
- 중복 클릭이 같은 명령을 두 번 생성하지 않는지 확인
- 승인 권한, 만료 명령, 단절 중 명령 차단 확인
- 재연결 후 명령 타임라인과 기체 상태 일치 확인
