# 개발 내역 — new_history (Kotlin·방산 DDD 전환)

`docs/new_roadmap/`(전환 계획)을 실제로 진행한 기록이다. FastAPI 기준 1~7단계 기록은
[`../legacy/`](../legacy/README.md)에 있고 더 이상 갱신하지 않는다.

## 파일 규칙

- 파일명: `0N_단계명_DayXX.md` — `docs/new_roadmap/0N_*.md`와 번호를 맞춘다.
- 각 문서는 아래 절을 포함한다.
  - **기간/관련 문서**: 로드맵·ADR·기획 문서 링크
  - **구현 내역**: 새로 만들거나 바꾼 파일과 역할
  - **설계 결정**: 로드맵에 없던 선택과 근거(큰 것은 ADR 링크)
  - **테스트/검증**: 실행한 시험과 결과(완료 게이트 충족 여부)
  - **남은 이슈**: 다음 단계로 이월되는 사항
- 단계가 완료된 시점에 작성한다. 단계 진행 중에는 "진행 중" 상태와 완료된 유닛만 적는다.
