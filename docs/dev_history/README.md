# 개발 내역 (dev_history)

`docs/roadmap/`이 "무엇을 할지"(계획)를 정의한다면, 이 폴더는 "실제로 무엇을 했는지"(기록)를
단계별로 남긴다. `docs/decisions/`(ADR)가 특정 결정 하나를 다루는 것과 달리, 여기서는 한 로드맵
단계 전체의 구현 내역·검증 결과·남은 이슈를 정리한다.

## 파일 규칙

- 파일명: `0N_단계_제목.md` — `docs/roadmap/0N_단계_*.md`와 번호를 맞춘다.
- 각 문서는 아래 절을 포함한다.
  - **기간/관련 문서**: 로드맵·작업분해·ADR 링크
  - **구현 내역**: 새로 만들거나 바꾼 파일과 역할
  - **설계 결정**: 로드맵에 없던 선택을 했다면 근거(ADR로 뺄 만큼 크면 ADR 링크)
  - **테스트/검증**: 실행한 테스트와 결과
  - **남은 이슈**: 다음 단계로 이월되는 사항
- 단계가 완료된 시점에 작성하고, 루트 `README.md`의 "현재 상태" 배지를 함께 갱신한다.
