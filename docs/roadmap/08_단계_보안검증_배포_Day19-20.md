# 8단계 — 기체 mTLS·통합 검증·배포 (Day 19~20)

## 목표

기체별 인증서와 mTLS, 사용자 접근 제어, 네트워크 장애 회귀시험을 완료하고 재현 가능한 결과물로 정리한다.

## 작업

- JWT 인증과 운영자·분석자·관리자 권한 적용
- 입력 크기·rate limit·CORS·보안 헤더 점검
- DB·Redis 외부 노출 제거와 secret 분리
- unit·integration·end-to-end 회귀시험
- 이미지 취약점 검사와 의존성 점검
- 데모 데이터, 실행 README, API 문서 정리
- 아키텍처·정합성·부하·보안 결과 보고서 작성
- 2~3분 시연 영상 촬영
- 개발 CA, 서버 인증서, 기체별 client certificate 구성
- 인증서 fingerprint와 device_id 매핑
- 만료·미등록·폐기·타 기체 인증서 거부 시험
- Command/Telemetry 계정과 ACL 분리 확인
- 배포 시 deployment 레코드 자동 등록

## 완료 기준

- 권한 없는 임무 변경과 감사 로그 조회가 차단된다.
- 빈 환경에서 문서만으로 실행 가능하다.
- 핵심 사용자 시나리오 E2E가 통과한다.
- 알려진 제한과 후속 개선 항목을 공개한다.
- 인증되지 않은 기체의 두 채널 연결이 모두 거부된다.
- 패킷 손실·지연·역순·단절·재동기화 회귀시험이 통과한다.
- 운용 로그에서 배포 Git SHA와 image digest를 역조회한다.

## 최종 산출물

Docker Compose 실행본, 개발용 인증서 생성 절차, OpenAPI 문서, 신뢰성·보안 시험 보고서, 장애 재현 로그, 시연 영상, 포트폴리오 README.
