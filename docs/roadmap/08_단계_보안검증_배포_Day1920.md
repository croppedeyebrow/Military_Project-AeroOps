# 8단계 — 보안·검증·배포 (Day 19~20)

## 목표

접근 제어와 전체 회귀시험을 완료하고 제3자가 재현 가능한 결과물로 정리한다.

## 작업

- JWT 인증과 운영자·분석자·관리자 권한 적용
- 입력 크기·rate limit·CORS·보안 헤더 점검
- DB·Redis 외부 노출 제거와 secret 분리
- unit·integration·end-to-end 회귀시험
- 이미지 취약점 검사와 의존성 점검
- 데모 데이터, 실행 README, API 문서 정리
- 아키텍처·정합성·부하·보안 결과 보고서 작성
- 2~3분 시연 영상 촬영

## 완료 기준

- 권한 없는 임무 변경과 감사 로그 조회가 차단된다.
- 빈 환경에서 문서만으로 실행 가능하다.
- 핵심 사용자 시나리오 E2E가 통과한다.
- 알려진 제한과 후속 개선 항목을 공개한다.

## 최종 산출물

Docker Compose 실행본, 소스 저장소, OpenAPI 문서, 테스트 보고서, 시연 영상, 포트폴리오 README.
