# 6단계 — 3D 상세 뷰어 (Day 14~15)

## 목표

선택 기체만 GLB 모델로 표현하고 실시간 자세값을 적용한다.

## 작업

- 라이선스가 명확한 저폴리곤 GLB 선정
- Three.js viewer와 로딩·오류 상태 구현
- 좌표축 변환 규칙 확정
- roll·pitch·yaw quaternion 적용
- 진행 방향과 센서 방향 보조선 표시
- 기체 변경 시 모델·리소스 정리

## 완료 기준

- 선택 기체와 3D 뷰어의 asset_id가 일치한다.
- 기준 자세와 ±회전 테스트가 예상 방향으로 보인다.
- timestamp가 2D 지도·상태 패널과 일치한다.
- 3D 로딩 실패 시 2D 관제가 정상 동작한다.

## 산출물

3D 상세 뷰어, 축 정의 문서, 자세 동기화 테스트.
