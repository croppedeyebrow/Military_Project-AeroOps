# 1단계 — 프로젝트 기반 (Day 1~2)

## 목표

모노레포, 공통 개발 규칙, Docker Compose, 최소 CI를 구축한다.

## 작업

- `frontend`, `backend`, `simulator`, `infra`, `docs`, `tests` 구성
- React/Vite와 FastAPI 초기화
- PostgreSQL/PostGIS, Redis Compose 구성
- health endpoint와 기본 화면 구현
- formatter, linter, unit test, 환경변수 예제 설정
- GitHub Actions에서 lint·test·build 실행

## 완료 기준

- 한 명령으로 전체 서비스가 실행된다.
- 프론트에서 백엔드 health 결과를 확인한다.
- DB migration이 빈 환경에서 성공한다.
- CI가 같은 검증을 재현한다.

## 산출물

저장소 구조, Compose, CI, 실행 README, 기술 결정 기록 1건.
