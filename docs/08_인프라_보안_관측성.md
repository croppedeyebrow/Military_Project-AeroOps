# 인프라·보안·관측성

## 적용 범위

Platform/Edge, Device DMZ, Mission Service, Data, AI와 Management Zone을 분리하고 Zero Trust와 Artifact 중심 배포를 적용한다.

## 공부할 개념

- TCP, TLS, DNS, reverse proxy, firewall
- Docker image·network·volume·resource limit
- OIDC/JWT, RBAC, workload identity
- PKI, X.509, mTLS, rotation·revocation
- SAST, SCA, secret scan, container/IaC scan
- SBOM, signature, provenance, VEX
- OpenTelemetry trace·metric·log correlation
- Prometheus metric type와 Grafana dashboard
- SLI/SLO, error budget, RPO/RTO
- backup/restore, incident response, runbook

## 핵심 SLI

- 수집→UI p95, Command 단계별 지연
- Queue 깊이, Drop·중복·역순 비율
- 재동기화 성공률과 UNKNOWN 지속시간
- AI Fallback·근거 없는 주장 비율
- 배포 성공·Rollback 시간과 복구 결과

## 실습

Gateway, Redis, PostgreSQL과 AI를 순차 중단하고 Trace·Log·Metric으로 장애 지점과 복구 시간을 설명한다.
