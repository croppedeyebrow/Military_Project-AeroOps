# 프론트엔드 아키텍처

## 책임과 화면

- 실시간 관제: 지도, 자산 목록, 경보, 선택 기체 상세
- 임무 관리: 임무 지점, 예정 경로, 지오펜스
- 이력 재생: 지도·3D·차트의 동일 시간축 재생
- 관리: 사용자, 자산, 감사 로그

## 시각화 규칙

| 대상 | 표현 |
|---|---|
| 전체 드론 | 방향 아이콘, 호출부호, 상태 색상 |
| 실제·예정 경로 | 실선·점선 |
| 선택 기체 | 저폴리곤 GLB와 자세값 |
| 통신 단절 | 회색 마지막 위치와 경과 시간 |
| 구역 | 임무·주의·금지 폴리곤 |

## 상태 관리

- 서버 데이터: TanStack Query
- 실시간 최신 프레임: WebSocket 전용 store
- 화면 선택·레이어: Zustand
- 재생 시각·배속: Replay Controller

장기 이력을 브라우저에 계속 누적하지 않는다. 최신 상태와 짧은 차트 버퍼만 유지하고 기간 이력은 API로 조회한다.

## 컴포넌트 경계

`OperationsMap`, `AssetList`, `AssetDetail`, `Vehicle3DViewer`, `AlertPanel`, `ReplayTimeline`, `TelemetryChart`로 분리한다. 3D 오류가 지도 관제를 중단시키지 않도록 오류 경계를 둔다.

## 검증

- 10대 아이콘 갱신 시 프레임 드롭 확인
- 선택 변경 시 GLB 메모리 해제
- WebSocket 재연결과 stale 상태 표시
- 동일 timestamp의 지도·3D·차트 일치
