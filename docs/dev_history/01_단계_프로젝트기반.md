> 이 문서는 `docs/dev_history/` 기록 관례가 생기기 전에 완료된 단계를 소급 정리한 것이다.

- 결정 기록: [`docs/decisions/0001-project-foundation.md`](../decisions/0001-project-foundation.md)

## 구현 내역

- 모노레포 구조 확정: `frontend`, `backend`, `simulator`, `infra`, `docs`, `tests`
- `frontend`: React + TypeScript + Vite 초기화, `/health` 조회 화면
- `backend`: FastAPI 초기화, `/health/live`·`/health/ready` 엔드포인트
- `infra`: Docker Compose(web, api, simulator(옵션), postgres, redis, prometheus, grafana,
  reverse-proxy), 각 서비스 Dockerfile
- `.github/workflows/ci.yml`: lint·test·build를 백엔드/시뮬레이터/프론트 3개 job으로 구성
- formatter/linter(ruff, mypy, ESLint 등), `.env.example` 각 서비스별 작성

## 테스트/검증

- `backend/tests/test_health.py`: health 엔드포인트 응답 확인
- `simulator/tests/test_main_stub.py`: CLI 임포트 가능 여부 확인
- `docker compose up`으로 전체 서비스 기동, 프론트에서 백엔드 health 조회 확인
