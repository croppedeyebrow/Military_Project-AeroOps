# 2단계 — 데이터 계약·시뮬레이터 (Day 3~4)

## 목표

`TelemetryFrame`과 `CommandEnvelope` 계약을 분리하고 재현 가능한 네트워크 장애 시뮬레이터를 만든다.

## 작업

- JSON Schema/Pydantic 모델 정의
- 위치·자세·상태의 단위, 축, 범위 문서화
- 원형·직선·경유지 비행 시나리오 구현
- 10대 × 1 Hz 정상 데이터 생성
- 중복·지연·역순·GPS 점프·단절 오류 주입
- seed와 scenario_id로 재현성 확보
- Command ACK·실행 결과·마지막 처리 command_id 시뮬레이션
- 손실률·지연 분포·재정렬 윈도우·단절 시간을 설정값으로 제공

## 완료 기준

- 정상 프레임은 계약 검증을 통과한다.
- 잘못된 위경도·배터리·각도는 거부된다.
- 동일 seed 실행 결과가 일치한다.
- 최소 6개 장애 시나리오 테스트가 통과한다.
- 같은 장애 profile과 seed에서 동일 sequence gap이 재현된다.
- Telemetry 데이터가 Command 계약으로 통과하지 않는다.

## 산출물

데이터 사전, JSON 예제, 시뮬레이터, 오류 시나리오 테스트.
