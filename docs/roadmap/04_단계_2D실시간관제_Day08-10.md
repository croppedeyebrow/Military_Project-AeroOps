# 4단계 — 2D 실시간 관제 (Day 8~10)

## 목표

10대의 위치·방향·상태를 실시간 표시하고 통신 단절 후 서버·기체 상태를 재동기화한다.

## 작업

- WebSocket 구독과 재연결 구현
- 자산 목록·검색·상태 필터 구현
- 방향 아이콘, 호출부호, 상태색 표시
- 실제 이동 경로와 데이터 신선도 표시
- 기체 선택과 상태 패널 연결
- 연결 끊김·stale·복구 UI 구현
- 마지막 sequence, state_version, 마지막 command_id 교환
- snapshot 적용과 미종결 명령 대조 로직 구현
- 재동기화 상태 배너와 sync event 기록

## 완료 기준

- 10대 아이콘이 식별 가능하게 갱신된다.
- 클릭한 기체와 상세 패널 정보가 일치한다.
- 통신 단절 시 마지막 위치와 경과 시간이 보인다.
- 재연결 후 최신 스냅샷으로 복구한다.
- 단절 중 누락 구간이 sequence gap으로 남는다.
- 재동기화 완료 전 위험 명령이 제한된다.
- 재연결 전후 최신 상태와 command 상태가 모순되지 않는다.

## 산출물

실시간 관제 화면, WebSocket 처리 코드, 화면 동작 영상.
