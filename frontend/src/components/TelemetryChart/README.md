# TelemetryChart

선택 기체의 시계열 값(배터리/고도/속도)을 재생 구간 전체에 대해 선 그래프로 보여주고,
재생 커서와 동기화한다. 7단계(`docs/roadmap/07_단계_이력재생_관측성_Day16-18.md`)에서
구현.

## 파일

- `scale.ts`: 시간/값 -> 픽셀 좌표 변환, SVG `path` `d` 문자열 생성(순수 함수,
  `scale.test.ts`로 검증 — React 컴포넌트 렌더 테스트는 이 프로젝트에 없다, `Vehicle3DViewer`
  때부터의 결정과 동일).
- `TelemetryChart.tsx`: `ReplayMap`/`ReplayVehicle3DViewer`/`ReplayAssetDetail`과 같은
  패턴으로 `useReplayStore`(커서·선택 기체)와 `dataset` prop(세션 전체 이력)을 받는다.
  다만 저 셋은 "그 순간 프레임 하나"만 필요한데 이 차트는 "구간 전체의 점들"이 한 번에
  필요하다는 점이 다르다.

## 설계 결정

- 외부 차트 라이브러리를 쓰지 않고 SVG를 직접 그린다 — `OperationsMap`의 방향 아이콘을
  스프라이트 대신 CSS 삼각형으로 직접 그린 것과 같은 결의 선택.
- `null` 값(아직 그 필드가 보고되지 않은 프레임)은 선을 끊지 않고 건너뛴다 — 0으로
  대체하면 "진짜 0%"와 "값 없음"을 구분할 수 없게 된다.
- y축 도메인은 데이터의 min/max에 10% 여백을 둔다(값이 전부 같으면 고정폭 여백) — 선이
  차트 테두리에 바로 붙어 잘려 보이지 않게.

## 의도적으로 하지 않은 것

- 차트를 클릭/드래그해서 재생 위치를 바꾸는 기능(차트 쪽 seek): `ReplayTimeline`의
  슬라이더로 이미 탐색할 수 있고, 완료 기준("커서 동기화")은 표시만 요구한다. 필요해지면
  `useReplayStore.seek()`를 그대로 연결하면 된다 — 이미 있는 액션이라 추가 자체는 쉽다.
- 여러 기체를 겹쳐 그리는 것: 지금은 선택된 기체 하나만 — 비교가 필요해지면 다음 단위.
