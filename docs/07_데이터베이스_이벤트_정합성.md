# 데이터베이스·이벤트·정합성

## 적용 기술

PostgreSQL/PostGIS는 업무·공간·원본 Event의 진실 원천, Redis Streams는 비동기 전달과 최신 Cache에 사용한다.

## 공부할 개념

- ACID, MVCC, Isolation Level, Lock
- Optimistic Lock과 unique constraint
- JPA Persistence Context와 N+1
- Flyway baseline·expand/migrate/contract
- PostGIS geometry/geography·GiST
- 시계열 Partition·BRIN·보존 정책
- At-least-once, idempotency, deduplication
- Transactional Outbox, consumer recovery, DLQ
- Event Time·Received Time·Clock Skew

## 적용 원칙

- Context별 테이블 소유권을 지정한다.
- Redis를 영구 진실의 원천으로 사용하지 않는다.
- 원본 Event는 불변으로, 최신 상태는 재생 가능한 Projection으로 관리한다.
- Dual Write 대신 Outbox를 사용한다.

## 실습

중복·역순·DB/Redis 중단을 주입하고 원본 수, Projection, Outbox와 Audit 결과를 대조한다.
