# 7단계 — 이벤트 재생·배포 추적 (Day 16~18)

## 목표

Telemetry·Command·경보·재동기화 이벤트를 동일 시간축으로 재생하고 당시 배포 버전까지 역추적한다.

## 작업

- 재생 구간·배속·일시정지·탐색 구현
- 이력 API 페이지·다운샘플링 구현
- 지도 위치, 3D 자세, 차트 커서 동기화
- Prometheus 메트릭과 Grafana 대시보드 구성
- 10대 × 1 Hz 장시간 시험
- WebSocket·Redis·DB 장애와 복구 시험
- operation_session과 deployment 등록·연결
- Git SHA, image digest, schema·rule·config version 기록
- append-only event log와 replay 전용 namespace 구현
- 실제 도착 순서와 event-time 순서 선택 재생
- 손실·지연·역순·명령 timeout 장애 시나리오 재현

## 완료 기준

- 같은 timestamp에서 세 시각화 값이 일치한다.
- 0.5×, 1×, 2× 재생이 가능하다.
- 수집량, 오류량, p95 지연, 연결 수를 확인한다.
- 20분 시험 결과와 병목 분석을 기록한다.
- 재생 이벤트가 실제 Command 채널로 전달되지 않는다.
- 장애 시점의 deployment와 규칙 버전을 조회할 수 있다.
- 동일 event log 재생 결과가 결정적으로 재현된다.

## 산출물

재생 화면, 이벤트 로그, 배포 추적 화면, Grafana 대시보드, 장애 재현 보고서.
