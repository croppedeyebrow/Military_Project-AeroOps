# 6단계 — C++ 결정적 Simulator (Day 10~11)

## 목표

Python Simulator의 검증된 Scenario를 C++에서 재현한다.

## 작업

- C++20·CMake·단위시험·Sanitizer 구성
- Simulation Clock과 고정 Seed PRNG 분리
- 위치·자세·배터리·통신 품질 모델 구현
- 손실·지연·역순·중복·단절·ACK 손실 Fault Injector
- Rust Gateway와 Versioned Contract 연동
- 실제 주입 원인과 관측 가능한 Event 분리 기록
- Python/C++ 동일 Scenario 결과 비교
- 100대×10Hz 탐색 부하와 메모리 검사

## 완료 게이트

동일 Seed에서 Event 순서가 재현되고, 정의된 수치 오차 내에서 기존 Simulator의 기대 결과와 일치한다.
