# 7단계 — 이력 재생·관측성 (Day 16~18)

## 목표

저장된 비행을 동일 시간축으로 재생하고 시스템 처리 성능을 측정한다.

## 작업

- 재생 구간·배속·일시정지·탐색 구현
- 이력 API 페이지·다운샘플링 구현
- 지도 위치, 3D 자세, 차트 커서 동기화
- Prometheus 메트릭과 Grafana 대시보드 구성
- 10대 × 1 Hz 장시간 시험
- WebSocket·Redis·DB 장애와 복구 시험

## 완료 기준

- 같은 timestamp에서 세 시각화 값이 일치한다.
- 0.5×, 1×, 2× 재생이 가능하다.
- 수집량, 오류량, p95 지연, 연결 수를 확인한다.
- 20분 시험 결과와 병목 분석을 기록한다.

## 산출물

재생 화면, Grafana 대시보드, 부하·장애 시험 초안.
