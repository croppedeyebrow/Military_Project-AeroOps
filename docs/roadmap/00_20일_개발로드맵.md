## 일정 원칙

- 매 단계 종료 시 실행 가능한 통합 상태를 유지한다.
- 다음 단계 기능보다 현재 단계 완료 게이트를 우선한다.
- LLM은 소형 양자화 모델 1개와 평가 세트 30건으로 제한한다.
- ML은 규칙·EWMA·Isolation Forest까지만 필수로 둔다.
- 실제 기체, LoRA 학습, Kubernetes, 실시간 영상 AI는 범위 밖으로 둔다.
- 매일 README의 실행법과 결정 기록을 함께 갱신한다.

## 단계별 태스크 묶음

### 1단계 — Foundation

- Monorepo, Compose, 환경 설정, Migration
- Telemetry·Command·Event JSON Schema
- REQ-ID/TEST-ID와 ADR 템플릿
- Lint·Unit Test·Secret Scan CI

### 2단계 — Simulator

- VirtualDrone, Flight/Battery Model, Simulation Clock
- 양방향 Fault Injector와 고정 Seed
- 생성·전송·폐기 Event Recorder
- Scenario Manifest와 기대 결과

### 3단계 — Data Plane

- Telemetry/Command Stream·권한 분리
- Sequence Gap, 중복, 역순, Late Event 처리
- PostgreSQL/PostGIS 저장과 Latest Projection
- Transactional Outbox와 Consumer 복구

### 4단계 — Operations UI

- MapLibre Fleet Map와 상태 Panel
- WebSocket 재연결과 Snapshot 복구
- STALE/DISCONNECTED·마지막 수신 시각 표시
- 재동기화 비교 화면

### 5단계 — Command & ML

- 요청·승인·Dispatch·ACK·실행·취소 상태 머신
- Policy Engine과 고위험 명령 승인
- 통신·배터리 Feature 생성
- 규칙·EWMA·Isolation Forest 평가와 Fallback

### 6단계 — 3D & RAG

- 선택 기체 Roll/Pitch/Yaw 시각화
- 운용 절차서 Parsing·Chunking·Indexing
- FTS+Vector Hybrid Retrieval·RRF
- 문서 ACL과 검색 평가

### 7단계 — LLM & MLOps

- 로컬 GGUF 모델과 구조화 출력
- 장애 Timeline·보고서 초안
- MLflow Experiment·Dataset·Model Registry
- Replay 평가, Shadow 결과, Rollback 시험

### 8단계 — Security & Evidence

- 기체별 인증서·mTLS·폐기 시험
- SAST/SCA/Container/IaC 검사
- SBOM·Image/Model Digest·Cosign 서명
- 전체 Scenario 회귀, Grafana, Portfolio Report

## 최종 필수 증거

1. Command와 Telemetry의 분리된 스트림·ACL
2. 명령 상태 전이와 승인·취소·timeout 기록
3. 손실·지연·역순·단절 시험 로그
4. 재연결 후 sequence·snapshot·미종결 명령 조정 결과
5. 유효·만료·폐기 인증서의 mTLS 시험
6. 동일 이벤트 재생을 통한 장애 재현
7. 운용 로그에서 Git SHA와 image digest 역조회
8. 이상 탐지 모델과 규칙 Fallback 비교 결과
9. RAG 검색 평가와 LLM 근거·구조화 출력 결과
10. 데이터셋·모델·프롬프트·배포 Lineage
11. SBOM·취약점 검사·Artifact 서명 검증 결과
